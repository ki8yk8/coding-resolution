# About the Project
I tried creating API using FastAPI for my project. This was my first time using FastAPI but I had some basic understanding of how backend works. The official doccumentation was really helpful.

The project implements multiple features including;
1. Authentication and 2FA with TOTP
2. User and Project creation, deletion and standard API
3. HTTP-only access tokens for security
4. Access control using FastAPI dependencies
